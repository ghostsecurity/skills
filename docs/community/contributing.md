# Contributing

Ghost Security AppSec Skills are fully open source and welcome contributions across all repositories. Whether you're fixing a bug, adding a detection rule, or building a new skill, here's how to get involved.

## Repository structure

Ghost Security AppSec Skills are organized across multiple repositories:

| Repository | Language | Purpose |
|---|---|---|
| [ghostsecurity/poltergeist](https://github.com/ghostsecurity/poltergeist) | Go | Secret scanner |
| [ghostsecurity/wraith](https://github.com/ghostsecurity/wraith) | Go | Dependency scanner |
| [ghostsecurity/reaper](https://github.com/ghostsecurity/reaper) | Go | MITM HTTPS proxy |
| [ghostsecurity/skills](https://github.com/ghostsecurity/skills) | Markdown/YAML | AI skills and orchestration |

> [!NOTE]
> **Contributing**
>
> Each repository has its own contributing guide with setup instructions, testing, and development workflows. Refer to the `CONTRIBUTING.md` in the relevant repository above.
